## English

Turn your phone or tablet into a shortcut panel for your Windows PC. Set up buttons for apps, websites, keyboard shortcuts, and Spotify, then use them from a browser on the same private network.

[Download the Windows ZIP](https://github.com/yaiha997/Stro-Deck/releases/tag/v1.0.2), extract it, and run `Stro-Deck.exe`. What would you put on your first page?
